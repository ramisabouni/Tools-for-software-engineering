# Exercise 5 — Regular Expressions

    Work in a copy of `starter/`; do not edit the instructor-managed course copy.

    ## Learning objectives

    - Translate requirements into anchored patterns.
- Distinguish BRE and ERE.
- Test both matching and non-matching cases.
- Build a boundary-focused corpus and report false classifications.

    ## Tasks

    1. Identify valid programming identifiers.
2. Extract course ticket identifiers.
3. Find messages containing an email-shaped token.
4. Document why shape validation is not full semantic validation.
5. Add shortest/longest valid values, just-outside boundaries, unexpected Unicode, and a long nonmatch to the corpus.
6. Compare the old and revised pattern classifications and explain every intentional difference.

    ## Deliverables

    - `patterns.txt`
- `test-patterns.sh`
- `corpus.tsv`
- `NOTES.md`

    ## Completion check

    Your commands or programs must run without errors, preserve the supplied input files,
    and produce repeatable results. Include a short `NOTES.md` describing assumptions and
    the commands used to test your work.
